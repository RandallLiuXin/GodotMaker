# Asset Runtime Pipeline

`ASSETS.md` is the sole runtime authority. Each logical runtime row records the
final loadable Godot type and `res://` path; source and reference evidence stay
in the Asset Skill result/report.

Use `asset-result-registration.md` and
`tools/asset_result_registration.py` to validate a complete Skill result,
atomically record its outputs, and derive the minimal worker snapshot. No entry
draft, manifest pointer, root index, or family-specific registration adapter is
part of this pipeline.
